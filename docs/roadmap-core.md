# رودمپ کور (سمت سرور) — چک‌لیستِ زنده

این فایل «تختهٔ کار» است: هر آیتم با انجام‌شدن تیک می‌خورد، و هر تست با **عدد و تاریخ و خط** در
جدولِ نتایج پایین ثبت می‌شود. هیچ ترانسپورتی بدون عدد روی خطِ ایرانی وارد چرخشِ همیشگی نمی‌شود.

قاعده‌های ثابت (از اندازه‌گیری‌های v1):
- در چرخشِ همیشگی **یک** ترانسپورت؛ بقیه فقط در نردبانِ نجات.
- کندکننده **per-flow** است: انتقالِ بزرگ باید رِنج‌محور باشد، نه یک جریانِ بلند.
- DNS داخل تونل (DoH)؛ IPv6 fail-closed؛ هیچ resolverِ مستقیم.
