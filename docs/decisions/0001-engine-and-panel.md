# ADR-0001 — موتور: Xray-core؛ پنل: خودمان

- وضعیت: پذیرفته
- تاریخ: 2026-11-04

## زمینه

نسخهٔ اول روی Xray-core بود و همان مسیرها با عدد سنجیده شدند: kcp/UDP حدود
۱.۰۷–۱.۸۲ MB/s، Reality روی TCP بعد از ~۲–۳ مگابایت به ۵–۵۵ KB/s خفه می‌شود،
و سرویس‌های تحریمی فقط با یک زنجیرهٔ خروجِ سمتِ سرور درست می‌شوند. اپِ فعلی
هم libbox/Xray را درون خود دارد.

## تصمیم

- **موتور همان Xray-core می‌ماند.** نسخه در `infra/ansible/roles/xray` pin می‌شود.
- **پنل را خودمان می‌نویسیم** (Express 5 + SQLite)، با همان سه قابلیتی که هیچ پنلِ
  آماده‌ای ندارد: امضای متادیتای آپدیت، تلمتری ناوگان، و زنجیرهٔ خروج.
- از پنل‌های آماده فقط **الگو و مدل داده** می‌گیریم، نه کد.

## گزینه‌های رد‌شده

- **Marzneshin / Marzban**: UI و API خوب، ولی سه قابلیتِ بالا باید از نو ساخته شوند و
  مهاجرتِ کاربران اجبار می‌شود.
- **Hiddify**: راه‌حلِ کامل، سریع‌ترین شروع، ولی کنترل روی ترانسپورت و زنجیره و اپِ
  اختصاصی کم می‌شود.
- **sing-box به‌جای Xray**: فقط اگر Hysteria2/TUIC در یک باینری لازم شود؛ اکنون لازم نیست.

## پیامدها

- سرعتِ تحویل کمتر از نصبِ یک پنلِ آماده، در عوض کنترل کامل روی مسیرِ داده.
- باید تست‌های پروفایل را از نسخهٔ اول به این ریپو بیاوریم (برشِ S2).
