# ADR-0002 — stage و prod جدا، باکس‌ها از بین‌رفتنی

- وضعیت: پذیرفته
- تاریخ: 2026-11-04

## تصمیم

- **stage**: باکسِ مستقل، دامنه/آی‌پی مستقل، دیتابیس مستقل، پورت‌های مستقل، سکرت‌های مستقل.
- **prod**: آلمان (نوشتنی) + ترکیه (peer). هیچ سکرتی با stage مشترک نیست.
- هر باکس با `ansible-playbook playbooks/site.yml` از صفر بازسازی می‌شود؛
  «سرور آماده» یعنی «باکس دورانداختنی»، نه «باکسِ دست‌کاری‌شده».
- وضعیتِ فعلی v1 دست نمی‌خورد: v2 موازی بالا می‌آید و با cutover جابه‌جا می‌شود.

## ترفیع (promotion)

1. CI سبز: تست‌ها + `check-no-secrets`.
2. `make drift ENV=stage` باید خالی باشد.
3. استقرار روی stage، سپس **چک‌لیست زندهٔ خط ایرانی**: ۲۰۸ روی `generate_204`،
   ۲۰۰ روی `gemini.google.com/app`، ۳۰۲ روی `alkalimakersuite-pa`، و ۱MB با ≥۵۰۰KB/s.
4. تأییدِ دستی محیطِ `production` در GitHub.
5. استقرار روی prod، همان چک‌لیست روی یک اکانتِ تست.

## بازگشت

- کانفیگ با timestamp در `/var/backups/ptunnel/` قبل از هر تغییر.
- بازگشت = اجرای مجدد نقش با `-e ptunnel_release=<previous>` یا برگرداندن snapshot و restart.
- اگر تغییر روی DNS/دامنه بود، TTL کوتاه (۳۰۰s) پیش از تغییر.
