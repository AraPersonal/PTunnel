# قراردادِ کلاینت ↔ سرویس (نسخهٔ ۲)

هر کسی که کورِ کلاینت را برای اندروید، ویندوز یا لینوکس می‌نویسد، فقط به این سند نیاز دارد.
هدف: «یک بار بخوان، بتوانی وصل شوی» — بدونِ خواندنِ کدِ ما.

## ۱) مسیرِ اتصال در یک نگاه

1. کلاینت از **bootstrap** فهرستِ نقطه‌های ورود را می‌گیرد (چند دامنه/آی‌پی، امضاشده).
2. با یوزرنیم/رمز لاگین می‌کند و **توکن** می‌گیرد.
3. پروفایلِ تونل را برای یک «تگِ ترانسپورت» می‌گیرد (`multi`, `reality`, `kcp`, …).
4. هستهٔ تونل را با آن پروفایل بالا می‌آورد و **سلامت** را می‌سنجد.
5. اگر پروفایل کار نکرد، **نردبان** را طی می‌کند (تگِ بعدی → باکسِ دیگر → …) و پلهٔ موفق را ذخیره می‌کند.
6. در طولِ نشست: تلمتریِ دسترس‌پذیری می‌فرستد و هر ۲۰ دقیقه پروفایل را تازه می‌کند.

## ۲) قاعده‌های تونل که سرویس تضمین می‌کند

- پروفایلِ `multi` امروز **یک** ترانسپورت در چرخش دارد (kcp)، بقیه فقط در نردبان.
- DNS **فقط** داخلِ تونل (DoH)؛ هیچ resolverِ مستقیمی مجاز نیست.
- IPv6 اگر کامل پشتیبانی نشود، **fail-closed** است (نه نشت).
- ترافیکِ چند دامنهٔ تحریمی از زنجیرهٔ خروجِ سمتِ سرور می‌رود؛ کلاینت کاری نمی‌کند.

## ۳) نقطه‌های سرویس (وضعیت)

| مسیر | وضعیت | کار |
|---|---|---|
| `GET /b` | موجود | bootstrap: فهرستِ endpointها + امضا |
| `POST /v1/login` | موجود | ورود؛ پاسخ شاملِ توکن، پلن، و **`channel: prod\|beta`** |
| `GET /v1/user/profile` | موجود | پروفایلِ کاربر، حجم/انقضا، کانال |
| `GET /v1/client/xray?tag=<tag>` | موجود | پروفایلِ تونل برای همان تگ |
| `GET /v1/locations` | موجود | فهرستِ باکس‌ها و کشور |
| `GET /v1/app/latest` | موجود | متادیتای آپدیتِ **امضاشده** |
| `POST /internal/reachability` | داخلی | گزارشِ دسترس‌پذیری (شبکه /۲۴، نتیجه) |
| `POST /v1/client/telemetry` | **در S2** | رخدادهای کلاینت: تلاشِ ورود، خطای هسته، پلهٔ موفق |

## ۴) احراز هویت و هدرها

- `Authorization: Bearer <token>` برای همهٔ مسیرهای `/v1` به‌جز bootstrap و login.
- هدرهای توصیه‌شده: `X-Client-Platform: android|windows|linux`، `X-Client-Version: <versionCode>`.
- سرور می‌تواند بر اساسِ پلتفرم، پروفایلِ متفاوت بدهد (فعلاً یکسان است).

## ۵) متادیتای آپدیت (امضا اجباری است)

```json
{"versionCode":66,"versionName":"0.66","url":"https://…/dl","spare":"https://…/dl",
 "sha256":"…","sizeBytes":39520726,"minVersionCode":49,"mandatory":false,
 "sig":"<ECDSA P-256 over url|sha256|versionCode>"}
```
قاعده: نصب فقط اگر امضا با کلیدِ عمومیِ داخلِ اپ معتبر باشد **و** `versionCode` بزرگ‌تر از نسخهٔ نصب‌شده.
دانلود باید **رِنج‌محور** باشد (اصلِ اندازه‌گیری‌شده: یک جریانِ بلند روی خطِ ایرانی خفه می‌شود).

## ۶) تلمتریِ دسترس‌پذیری

```json
POST /internal/reachability
{"network":"37.156.12","verdict":"ok|tunnel_failed|server_unreachable","port":8443,"box":"de-1"}
```
`network` سه اکتتِ اول است (حریمِ کاربر حفظ می‌شود) و برای تصمیمِ «کدام درب برای کدام خط» استفاده می‌شود.

## ۷) آزمونِ پذیرشِ کلاینت (بدونِ کدِ ما)

```bash
curl -s https://<stage>/b | jq .
TOKEN=$(curl -s -X POST https://<stage>/v1/login -d '{"username":"…","password":"…"}' | jq -r .token)
curl -s -H "Authorization: Bearer $TOKEN" 'https://<stage>/v1/client/xray?tag=kcp' | jq .outbounds[].tag
curl -s -o /dev/null -w '%{http_code}\n' --socks5-hostname 127.0.0.1:18080 https://www.google.com/generate_204   # 204
curl -s -o /dev/null -w '%{http_code}\n' --socks5-hostname 127.0.0.1:18080 https://gemini.google.com/app           # 200
```
