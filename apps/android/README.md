# اپ اندروید (پایه: v0.64)

این پوشه سورسِ اپ است که از نسخهٔ ۰.۶۴ گرفته شده تا تیم روی آن کار کند.

## چه چیزی عمداً اینجا نیست

- `app/libs/libv2ray.aar` (۵۸MB) — کورِ قدیمی. تصمیمِ جانشین در `docs/decisions/0005-client-core.md`
  است و بخشِ کور قرار است از نو نوشته شود؛ آوردنِ یک باینریِ ۵۸MB به گیت فقط تاریخچه را سنگین می‌کند.
- فایل‌های خروجیِ build و APKهای قدیمی.

## وضعیت

- UI، سرویس VPN، نردبان، آپدیت و تلمتری داخلِ همین سورس هستند.
- بخشِ کور (`libv2ray` / `VpnRuntime`) حذف خواهد شد و پشتِ یک interface می‌نشیند؛ تا آن زمان build
  نیاز به AAR دارد (از ریلیزِ v1 یا build محلیِ libbox).

## ساخت

```bash
cd apps/android
./gradlew :app:testDebugUnitTest     # تست‌های منطق (بدونِ نیاز به گوشی)
./gradlew :app:assembleDebug          # نیاز به Android SDK + AARِ کور
```

## امضای بیلد

`debug.keystore` عمداً در گیت است (رمز `android`، فقط برای بیلدِ دیباگ). کلیدِ امضای release هرگز وارد ریپو نمی‌شود و فقط در GitHub Secrets می‌نشیند؛ تا آن زمان فقط بیلد دیباگ ساخته می‌شود.
