# ptunnel-core

سرورِ هستهٔ PTunnel و پنلِ کنترلش، از نو و به‌صورت بازتولیدپذیر.

این ریپو **از صفر** ساخته شده تا کانفیگ سرور از حالتِ «دستی روی باکس» بیرون بیاید و به یک
وضعیتِ قابلِ بازتولید، قابلِ بازبینی و قابلِ تحویل به چند نفر تبدیل شود. کدِ نسخهٔ قبلی و
اندازه‌گیری‌هایش به‌عنوان مرجع در `docs/reference-v1.md` فهرست شده‌اند؛ اینجا کپی نمی‌شوند.

## قواعدِ طلایی

1. **هیچ‌کس روی باکس دستی ادیت نمی‌کند.** کانفیگ فقط از `infra/ansible` می‌آید؛ انحراف با
   `make drift` پیدا می‌شود.
2. **هیچ سکرتی در گیت نیست.** کلیدها در Ansible Vault / GitHub Environments می‌نشینند و
   CI پیش از هر چیز همین را چک می‌کند.
3. **stage و prod کاملاً جدا هستند**: باکس جدا، دامنهٔ جدا، دیتابیس جدا، پورت‌های جدا، سکرت‌های جدا.
4. **ترفیع فقط با مدرک**: تست‌های CI → `ansible --check` تمیز → تستِ زندهٔ خطِ ایرانی → تأییدِ دستی.
5. **هیچ تغییری روی prod بدونِ برنامهٔ بازگشت.**

## ساختار

    apps/panel          پنل/API (Express 5) — قلبِ کنترل: حساب‌ها، پروفایل، آپدیت، تلمتری
    infra/ansible       بازتولیدِ کاملِ باکس‌ها (base, xray, nginx, exit_chain)
    docs/decisions      ADR: چرا این‌ها را این‌طور انتخاب کردیم
    .github             CI، مالکیت کد، قالب PR

## محیط‌ها

| محیط | محل | هدف |
|---|---|---|
| dev | همین ماشین، `make dev` | توسعهٔ روزمره، بدون اثر روی کاربر |
| stage | باکسِ جدا (inventories/stage) | اثباتِ تغییر پیش از prod، با همان تست‌های خطِ ایرانی |
| prod | آلمان (inventories/prod) | سرویسِ زنده |
| peer | ترکیه (inventories/prod، گروه peer) | پرشِ خروج برای سرویس‌های تحریمی |

## شروعِ سریع

    make install     # نصبِ وابستگی‌های پنل
    make test        # تست‌های واحد + بررسیِ نبودِ سکرت
    make infra-check # syntax-check آنسیبل
    make dev         # اجرا روی 127.0.0.1:8080

## مسیرِ ساخت (برش‌ها)

1. **S1 — اسکلت و CI** (همین حالا): پنلِ حداقلی، بازتولیدِ باکس با Ansible، گیت‌های CI.
2. **S2 — حساب و پروفایل**: کاربر، token، سازندهٔ پروفایل Xray برای هر تگ، تزریقِ کاربر در کور.
3. **S3 — زنجیرهٔ خروج**: نقشِ `exit_chain` با همان قواعدِ اندازه‌گیری‌شده (اسمِ جواب‌دهنده، قاعدهٔ خانواده).
4. **S4 — تلمتری ناوگان**: گزارشِ دسترس‌پذیری، `/geo`، شمارشِ هر اینباند.
5. **S5 — آپدیتِ امضاشده**: متادیتای امضا‌شده، دانلودِ رنج‌محور، گیت‌های امنیتی.
6. **S6 — مهاجرت**: cutover از v1 با برنامهٔ بازگشت.

جزئیاتِ تصمیم‌ها: `docs/decisions/`.
